# 少儿英语辅导微信小程序 — 项目文档

## 项目概述

基于微信小程序的少儿英语在线辅导系统，为 3-12 岁儿童提供在线课程学习、作业提交、成绩查询、词汇记忆等功能。支持 **学生、家长、教师** 三种用户角色。

### 技术栈

- **前端**: 微信小程序原生框架 (WXML, WXSS, JS)
- **后端**: Node.js + Express
- **数据库**: MySQL 8.0
- **认证**: JWT Token
- **运行环境**: WSL (Windows Subsystem for Linux)

## 数据库设计

- **数据库名**: `english_tutoring_system`
- **字符集**: utf8mb4
- **共 15 张表**:

### 用户体系
| 表名 | 说明 |
|------|------|
| users | 用户（含角色：admin/teacher/student/parent） |
| teachers | 教师详细信息（资质、经验、专长） |
| students | 学生详细信息（年级、学校、英语水平） |
| parents | 家长详细信息（职业、教育背景） |

### 课程体系
| 表名 | 说明 |
|------|------|
| categories | 课程分类（基础英语、口语训练等6类） |
| courses | 课程（含价格、等级、评分） |
| lessons | 课时（每个课程含多个课时） |
| enrollments | 报名记录（用户-课程关联） |

### 学习体系
| 表名 | 说明 |
|------|------|
| study_records | 学习记录（时长、进度） |
| vocabulary | 词汇库（10个初级词汇） |
| user_vocabulary | 用户词汇学习（掌握度、复习计划） |

### 作业与成绩
| 表名 | 说明 |
|------|------|
| assignments | 作业（含截止日期、总分） |
| submissions | 作业提交（含评分、反馈） |
| scores | 成绩记录（关联作业或测验） |

### 消息
| 表名 | 说明 |
|------|------|
| messages | 消息通知（作业提醒、成绩通知） |

## 快速启动

### 前提条件
- WSL（Windows Subsystem for Linux）
- Node.js v18+
- MySQL 8.0（已在 WSL 中安装）
- 微信开发者工具

### 1. 启动数据库
```bash
sudo service mysql start
```

### 2. 启动后端服务
```bash
/tmp/testserver/start.sh
```

或双击 `start_server.bat`（Windows 桌面）

### 3. 启动小程序
用微信开发者工具打开 `miniprogram` 目录，编译运行。

### 4. 验证
```bash
curl http://localhost:3000/health
```
